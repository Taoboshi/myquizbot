# Telegram Quiz Bot

Этот проект представляет собой Telegram-бота для проведения тестов (квизов), построенного с использованием `python-telegram-bot` и `Flask`. Бот поддерживает многопользовательский режим, сохранение прогресса, работу с ошибками и систему администрирования.

## Основные возможности

- **Многопользовательские тесты**: Пользователи могут выбирать различные предметы и тесты.
- **Различные режимы прохождения**:
  - По порядку.
  - Вразброс (рандомно).
  - С конца.
  - С определенного номера вопроса.
  - Режим тренировки (мини-тест).
- **Сохранение прогресса**: Поддержка активных сессий, позволяющая продолжить тест с того же места.
- **Работа с ошибками**: Бот запоминает ошибки пользователя и предлагает режим "Разбор ошибок".
- **Избранное**: Возможность добавлять сложные вопросы в избранное для последующего изучения.
- **Статистика и рейтинги**: Личная статистика пользователя и топ-10 лучших результатов по каждому тесту.
- **Админ-панель**: Мощный инструмент для управления пользователями, просмотра статистики, экспорта данных в CSV, рассылки сообщений и проверки целостности тестов.
- **Поддержка баз данных**: Работает как с SQLite (для локальной разработки), так и с PostgreSQL (для продакшена, например, на Render/Neon).
- **Отказоустойчивость**: Использование консультативных блокировок (advisory locks) в PostgreSQL для предотвращения одновременного запуска нескольких инстансов бота (polling lock).

## Структура проекта

- `quiz_bot/`: Основной пакет с исходным кодом.
  - `admin.py`: Логика административной панели.
  - `app.py`: Инициализация и запуск Telegram-бота.
  - `config.py`: Конфигурационные параметры.
  - `handlers.py`: Обработчики команд и callback-запросов.
  - `loader.py`: Загрузка и валидация тестов из JSON-файлов.
  - `storage.py`: Слой абстракции для работы с базой данных (SQLite/PostgreSQL).
  - `runtime.py`: Управление состоянием пользователей в памяти и Flask-сервер для health checks.
- `tests/`: Папка с JSON-файлами тестов и юнит-тестами.
- `telegram_quiz_bot.py`: Точка входа для запуска бота.

## Требования

- Python 3.10+
- Переменные окружения:
  - `TELEGRAM_BOT_TOKEN`: Токен вашего бота от BotFather.
  - `DATABASE_URL` (опционально): URL для подключения к PostgreSQL. Если не задан, используется SQLite.
  - `ADMIN_IDS`: ID администраторов через запятую (настраивается в `config.py` или коде).

## Установка и запуск

1. Клонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Установите токен бота:
   ```bash
   export TELEGRAM_BOT_TOKEN="your_token_here"
   ```
4. Запустите бота:
   ```bash
   python telegram_quiz_bot.py
   ```

## Добавление тестов

Тесты добавляются в папку `tests/` в формате JSON. Бот автоматически подхватывает новые файлы при запуске. Структура JSON должна соответствовать установленному формату (см. `tests/oziz_module_2.json`).
